# Handoff: сайт массажной студии HANDS (Laravel + Blade)

> Дизайн-хэндофф от Claude Design. На него ссылается основное ТЗ (`docs/tz-hands.md`)
> за готовым контентом услуг (раздел 9), мастеров (раздел 10) и главной (раздел 11),
> а также за полными дизайн-токенами (раздел 8). Референсы вида — `docs/design/*.dc.html`.

---

## 1. Что это

Одностраничный + внутренние страницы сайт массажной студии **HANDS** (Могилёв, проезд
Пожарского 3Б). Стиль — премиум/люкс: кремовый фон, тёплая тёмная фотография, бронзово-золотые
акценты, крупная антиква (serif) + чистый гротеск (sans).

Страницы:
1. **Главная** — обложка, услуги, о студии, мастера, подарочные сертификаты, Яндекс-карта + контакты, форма записи, FAQ.
2. **Страница услуги** — один шаблон на все услуги, данные по slug.
3. **Страница мастера** — один шаблон на всех мастеров, данные по slug.
